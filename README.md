# PyEditor — 手机上的极简 Python 代码编辑器

> **“极致的轻量，极致的深度。”**
> 一个跑在 Android 上的 Python 编辑器 + 完整的 CPython 3.12 运行环境 + 纯 Python 包管理器。
> 整体安装包体积仅 **< 12 MB**，却拥有 C++ 自绘内核、智能折叠、正则替换与 C 扩展编译能力。

## 🌟 为什么选择 PyEditor？

在动辄上百兆的移动端开发环境里，PyEditor 是一个“异类”。它拒绝了臃肿的第三方 UI 库，用纯 C++ 和原生 Java 手搓了词法分析与自绘渲染引擎，只为给你带来极其丝滑的敲代码体验。

### 🚀 核心亮点

*   **极致轻量**：极小的安装包，秒装秒开。拒绝冗余的第三方依赖，连标准库都经过极限压缩（LZMA2）。
*   **C++ 原生内核**：词法高亮、符号索引、语法检查全在底层 C++（JNI）完成，游标渲染、行号对齐丝滑不卡顿。
*   **完整的运行环境**：内置完整的 CPython 3.12 环境（530+ 标准库模块），支持独立进程运行，死循环可强杀不卡 UI。
*   **硬核 C 扩展编译**：结合 Shizuku 权限与 Zig 编译器，支持在手机上直接编译并 `import` 原生 `.c` 模块。
*   **现代化的代码折叠**：不仅支持函数/类/嵌套代码块（含多行签名），还独创支持**单行与多行**的 `list` / `dict` / `tuple` / `set` 字面量折叠。
*   **代码透镜（CodeLens）**：实时显示函数的调用次数、类的属性与方法统计，点击即可快速查找引用。
*   **大厂级手势交互**：适配 Android 13+ 预测性返回手势，侧边栏与子页面支持跟手拖拽、视差回弹与取消。

## 🛠️ 高级编辑特性

*   **正则查找与替换**：支持跨行匹配（`\n`）、正则表达式分组（`$1`）、全词匹配，且全部替换支持单步撤销。
*   **彩虹缩进参考线**：根据代码块层级动态计算颜色渐变，支持自定义首尾颜色。
*   **自定义代码片段（Snippets）**：内置 21 个常用片段，支持自定义模板，使用 `${cursor}` 精准定位插入后的光标位置。
*   **纯文本兼容**：非 `.py` 文件（如 txt、json、xml）自动切换为纯文本模式，关闭高亮与折叠，保证大文件打开速度。
*   **内置终端（Shizuku）**：支持通过 Shizuku 获取 shell 权限，直接在 App 内执行系统级命令。

## 📦 安装与使用

1. 前往本仓库的 [Releases](https://github.com/CYX-PyEditor/PyEditor/releases/latest) 页面，下载最新的 `PyEditor-x.x.x.apk` 安装即可。
2. 首次运行会解压标准库，请耐心等待几秒钟。
3. 如果要使用 C 扩展编译功能，请在“设置 -> 编译器”中配置好头文件与 Zig 工具链，并确保 Shizuku 已授权。

## 🧱 技术架构

*   **UI 层**：原生 Android 自绘 View（无第三方 UI 框架）。
*   **核心层**：C++ 引擎，通过 JNI 与 Java 交互，处理文本缓冲、词法分析与折叠计算。
*   **构建链**：不使用 Gradle。自写 `aapt` / `javac` / `d8` / `apksigner` 脚本打包，包含自定义的 `pack.py` 处理资源对齐。
*   **安全**：全量开启 R8 混淆与裁剪，并严格保留 JNI 回调与 Android 生命周期白名单。

## ⚠️ 已知限制

*   仅支持 `arm64-v8a` 架构。
*   内置的 CPython 未编译 `ssl` / `_socket` 等模块（网络请求需依赖 Java 层实现）。
*   C 扩展编译目前仅支持单文件 `.c`，暂不支持 `.cpp` 或多文件工程。
