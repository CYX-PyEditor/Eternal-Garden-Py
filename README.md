# YHHYPy (永恒花园) — 手机与平板上的极客级 Python 编辑器

> **“极致的轻量，极致的深度。”**
> 一个跑在 Android 上的 Python 编辑器 + CPython 3.12 运行环境 + 纯 Python 包管理器。
> 整体安装包体积仅 **10.96 MiB**，却拥有 C++ 自绘内核、自由多区、沉浸式手势与 C 扩展编译能力。

**当前版本：5.6.4（versionCode 87）** · Android 7.0+ · arm64-v8a · GPL-3.0

---

## 🌟 为什么选择 YHHYPy？

在动辄上百兆、依赖臃肿的移动端开发环境里，YHHYPy 是一个「异类」：它不用 Gradle、不用 AndroidX、
不用任何第三方 UI 库 —— 词法分析、符号索引、折叠、语法检查用纯 C++ 手写，界面是自绘 View。
所以它能做到：

* **10.96 MiB 的完整 Python 环境**：CPython 3.12.8 + 530 个标准库模块（LZMA2 压缩）+ 编辑器 + 包管理器。
* **打字不卡**：自绘视图只画可见行，每帧一次 JNI 取记号，行宽 / 行文本按版本号缓存。
* **手机上真的能用**：行号、补全、折叠、波浪线、选区手柄、MiniMap、多区、终端、REPL 全都为触屏重做。

## 🚀 核心亮点

*   **C++ 原生内核**：词法高亮（15 类记号）、符号索引、折叠、24 类语法检查都在底层算。
*   **全功能运行环境**：独立进程跑 CPython 3.12.8，`input()` 可交互，死循环可随时中断。
*   **硬核 C 扩展编译**：配合 Shizuku 与本地工具链，直接在手机上把单文件 `.c` 编成 `.so` 供 Python `import`。
*   **次世代折叠**：除了 `if/for/while/def/class`，还支持 `list` / `dict` / `tuple` / `set` 字面量行内折叠，
    `else/elif/except/finally/case` 子句也能单独折；抽屉里四个一键命令。
*   **代码透镜（CodeLens）**：函数行尾显示被使用次数，类行显示属性/方法数，点一下直接查引用。
*   **24 类语法检查**：赋值目标、缺右值、关键字当函数名、缩进、参数、import、数字字面量、
    模块级 `await/yield`、孤立子句、`type` 缺 `=`、f-string、`except*` 等，规则对齐 CPython。
*   **选区手柄**：选中后两端圆形手柄，拖动时边缘自动滚动，松手工具条自动回来。
*   **右侧大纲导航（MiniMap）**：从右边缘左滑呼出，按比例画函数/类/方法与错误红点，打开时**挤压**正文而不是遮盖。
*   **状态栏可配**：横屏 / 竖屏各自「显示 + 顶部/底部」，也能放进顶栏「常用」。
*   **行分隔线 / 彩虹缩进参考线 / 载入 .ttf / 中英双语 / 预测性返回 / 沉浸式全屏。**

## 📱 多区与「关掉不丢」

*   **一个区可以是**：编辑区、终端（Shizuku / root / 本应用身份）、解释器（CPython REPL）。
*   **任意拆分**：顶栏 `+` = 类型 × 在右侧 / 在下方拆分，新区拆在焦点区旁边，最多 6 个；
    上 1 下 2、左 2 中 1 右 2、2×2、3×2… 都能拼；设置里 `1×2…1×6` 是一键重排预设。
*   **分割线是独立对象**：拖哪段动哪段（2×2 四段线互相独立）；靠近相接的线 10dp 磁吸、
    15dp 缓冲锁死、松手精确落子。
*   **不会穿透**：分割线只能在自己的走廊里走，拖不进任何不属于它的区；被挡住时精确停在
    与隔壁线对齐的位置；相连的整条线一起动就能走时自动升级成整线拖动；每帧落子还有全格子重叠校验兜底。
*   **不会留空洞**：加区 / 挤掉 / 关区 / 拖动松手 / 恢复 / 保存前都会做一次「合法划分」检查
    （按分割线切成单位格，逐格数被几个区覆盖），重叠和空洞会被自动吃掉。
*   **关掉不丢**：区数、拆分形状、每条线位置、每个区的类型、每个编辑区打开的文件与光标、焦点区
    —— **布局一变就存**（焦点切换、换文件也存），同步 `commit()` + `fsync` 落盘，被系统划掉也不丢；
    换屏幕尺寸等比缩放，数据异常退回网格但**不会丢区**。

## 🛠 高级编辑特性

*   **正则查找 / 替换**：跨行 `\n`、分组引用 `$1`、全部替换只需一次撤销。
*   **代码片段**：内置 21 个高亮片段，`${cursor}` 指定落点，可改可加。
*   **纯文本兼容**：打开 txt / json / xml / js 自动降级纯文本模式。
*   **文件**：走系统文件选择器（SAF），不需要存储权限；最近文件、多页签、后台自动保存。
*   **主题**：深色 / 浅色 / 午夜蓝 / 品红·浅蓝 + **任意多个自定义命名主题**；
    15 类记号逐项配色 + B/I，字号 / 行距 / 字体族（含 `.ttf`）全可调。

## 🧱 技术架构与体积构成

*   **UI 层**：原生 Android 自绘 View（零第三方 UI 库）。
*   **核心层**：C++ 引擎 `libpyedit.so`（179 KB），通过 JNI 与 Java 交互。
*   **构建链**：不用 Gradle；自写脚本调 aapt2 / javac / R8 / apksigner，并用 `tools/pack.py`
    处理 `resources.arsc` 4 字节与 `.so` 16 KB 对齐。
*   **体积构成**：
    *   `libcpython.so`（CPython 3.12.8）：7.90 MB
    *   `libc++_shared.so`：1.42 MB
    *   `stdlib.tar.xz`（530 模块）：1.69 MB
    *   `libpyedit.so` 179 KB + R8 后 dex 463 KB + 资源/清单 ~67 KB

## ⚠️ 已知限制

*   仅 **arm64-v8a**（Android 7.0+），不支持 32 位 / 模拟器。
*   内置 CPython 未编译 `ssl`：Python 层 HTTPS 不可用（装包下载由 Java 层接管）。
*   `pip` 只装纯 Python wheel，不解析版本冲突；C 扩展只支持单文件 `.c`。
*   语法检查是轻量结构检查（不做 AST）；折叠基于缩进，极端怪写法不保证正确。
*   多区上限 6 个；某方向拖不动是几何约束在保护布局（再拖就会穿透）。
*   分区记忆只恢复位置 / 类型 / 文件 / 光标：终端与解释器的历史输出不保存，
    没保存过的新文档恢复后是空的 `未命名.py`。
*   装包必须手动点（仓库不提供自动更新）。

## 🔧 从源码构建

```bash
tar xzf PyEditor-5.6.4-src.tar.gz && cd PyEditor-src-5.6.4/original
./build.sh          # → dist/PyEditor.apk
```

依赖：clang-19、Android sysroot + libc++、JDK 17、`/opt/android-sdk/build-tools-tmp`
（d8 / apksigner）、aapt2。流程：clang 交叉编译 `libpyedit.so` → aapt2 处理资源 →
javac（bootclasspath 用 API 30 android.jar）→ d8 + R8 → `tools/pack.py` 对齐打包 → apksigner。

> 路径含中文时，javac 前需要 `export LC_ALL=C.UTF-8`（build.sh 已内置）。
