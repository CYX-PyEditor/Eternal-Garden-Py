# YHHYPy (永恒花园) — 手机与平板上的极客级 Python 编辑器

> **“极致的轻量，极致的深度。”**
> 一个跑在 Android 上的 Python 编辑器 + CPython 3.12 运行环境 + 纯 Python 包管理器。
> 整体安装包体积仅 **10.89 MiB**，却拥有 C++ 自绘内核、多编辑区、沉浸式手势与 C 扩展编译能力。

## 🌟 为什么选择 YHHYPy？

在动辄上百兆、依赖臃肿的移动端开发环境里，YHHYPy 是一个“异类”。它拒绝了笨重的第三方 UI 框架和 AndroidX，用纯 C++ 和原生 Java 手搓了词法分析与自绘渲染引擎，为你带来真正的桌面级丝滑体验。

### 🚀 核心亮点

*   **极致轻量**：安装包仅 **10.89 MiB**。连标准库都经过 LZMA2 极限压缩，绝不浪费你手机的一寸空间。
*   **C++ 原生内核**：词法高亮、符号索引、实时折叠均由底层 C++ 引擎计算，即使处理大文件也能保持丝滑顺畅。
*   **全功能运行环境**：内置完整的 CPython 3.12 环境（530+ 标准库模块），独立进程运行，支持 `input()` 交互，死循环可随时中断。
*   **硬核 C 扩展编译**：结合 Shizuku 权限与 Zig 编译器，能在手机本地直接编译 `.c` 文件，并生成 `.so` 供 Python `import`。
*   **次世代折叠体验**：不仅支持传统的 `if/for/while` 代码块折叠，还独创支持多行/单行的 `list` / `dict` / `tuple` / `set` 字面量行内折叠！
*   **代码透镜 (CodeLens)**：在代码行旁实时显示函数的调用次数、类的属性/方法统计，点击即可快速查找全局引用。

## 📱 多编辑区与沉浸式体验

专为平板、折叠屏和横屏重度用户打造：

*   **多编辑区 (Multi-Pane)**：支持最高 4 个编辑区同开（手机 2 个，平板 4 个）。
*   **自适应布局**：横屏左右分屏，竖屏自动切换为上下分屏，完美适配各种姿态。
*   **物理级交互**：拖拽分割线将某个区挤到边缘即可“吞噬”关闭；长按分割线进入换位模式，点击两个区即可瞬间交换文件状态。
*   **预测性返回手势**：完美适配 Android 13+ 的全面屏手势，子页面支持跟手拖拽、视差回弹与取消。
*   **沉浸式横屏**：横屏自动隐藏状态栏，按刘海安全区动态避让，代码区铺满整个屏幕。

## 🛠️ 高级编辑特性

*   **正则查找与替换**：常驻底部查找栏，支持跨行匹配（`\n`）、分组引用（`$1`），全量替换只需一次撤销即可恢复。
*   **自定义代码片段**：内置 21 个高亮片段，支持 `${cursor}` 自定义光标落点，且支持随意修改或新增。
*   **彩虹缩进参考线**：根据代码块层级动态计算颜色渐变，支持自定义首尾颜色。
*   **纯文本兼容**：打开非 `.py` 文件（如 txt、json、xml）时自动降级为纯文本模式，保证极速响应。
*   **R8 深度混淆**：构建时执行 R8 强混淆与裁剪，既压缩了体积，又防止了逆向破解。

## 📦 安装与使用

1.  前往 [Releases](https://github.com/CYX-PyEditor/PyEditor/releases) 页面，下载最新的 `YHHYPy-x.x.x.apk` 安装。
2.  首次运行 App 会解压标准库，请耐心等待几秒钟。
3.  如果要使用 C 扩展编译功能，请在“设置 -> 编译器”中配置好头文件与 Zig 工具链，并确保 Shizuku 已授权。

## 🧱 技术架构与体积构成

*   **UI 层**：原生 Android 自绘 View（零第三方 UI 库）。
*   **核心层**：C++ 引擎（`libpyedit.so`，约 141 KB），通过 JNI 与 Java 交互。
*   **构建链**：不使用 Gradle。自写 `aapt2` / `javac` / `d8` / `apksigner` 脚本打包，自定义 `pack.py` 处理 16KB 对齐。
*   **体积构成**：
    *   `libcpython.so` (CPython 3.12)：7.90 MB
    *   `libc++_shared.so` (C++ 运行时)：1.42 MB
    *   `stdlib.tar.xz` (标准库)：1.68 MB
    *   `libpyedit.so` (自绘内核) + 混淆后的 Java UI + 资源：仅约 581 KB

## ⚠️ 已知限制

*   仅支持 Android 7.0+ (arm64-v8a 架构)。
*   内置 CPython 未编译 `ssl` / `_socket`，Python 层无法直接发 HTTPS 请求（App 的 pip 下载由 Java 层接管）。
*   C 扩展编译目前仅支持单文件 `.c`，暂不支持 `.cpp` 或多文件工程。
